# Task 21 – Basic SQL SELECT

## Objective
To practice basic SQL queries using MySQL and PostgreSQL, including SELECT, WHERE, and ORDER BY statements.

## Tools Used
- MySQL
- PostgreSQL

## Dataset
Northwind-inspired sample dataset.

Tables used:
- Customers
- Products
- Orders
- OrderDetails

## Queries Performed
1. Display all customers.
2. Select specific customer columns.
3. Filter customers by country.
4. Filter products by price.
5. Use multiple WHERE conditions.
6. Sort products by price in descending order.
7. Sort customers alphabetically.
8. Filter orders by date.
9. Search product names using LIKE.
10. Display the five cheapest products using LIMIT.

## SQL Concepts Covered
- SELECT – Retrieve data from tables.
- WHERE – Filter records based on conditions.
- AND – Combine multiple conditions.
- ORDER BY – Sort query results.
- ASC – Sort in ascending order.
- DESC – Sort in descending order.
- LIKE – Search for specific text patterns.
- LIMIT – Restrict the number of returned rows.

## Deliverables
- MySQL SQL script
- PostgreSQL SQL script
- 10 SQL queries
- Query output files
- Task report

## Conclusion
Successfully completed Task 21 by writing and executing 10 basic SQL queries using MySQL and PostgreSQL. Practiced data retrieval, filtering, and sorting to strengthen SQL fundamentals.
